品牌与工作流

这一版把 CCCode 的品牌展示、CC API 账户信息和任务执行进度整合到工作台里，也补上了 Bark 通知和一套可单独检查任务抽屉的演示入口。

新功能
- 侧边栏底部使用 CC Logo，并在可用时显示 CC API 账户余额；点击 Logo 可以打开关于页面。
- 新增结构化任务计划：智能体报告任务后，右上角会显示任务计划入口，右侧抽屉可以查看步骤、进度、耗时和预估时间。
- 任务计划支持暂停、继续、重试和停止，并会保留正在执行或失败的任务状态，方便回来继续查看。
- 新增临时 `--task-plan-demo` 启动参数，用三个预设任务演示任务入口和右侧抽屉；演示数据与真实会话隔离。
- Bark 通知默认使用 CC AI API Logo 作为通知头像，同时保留自定义头像和空头像配置能力。

改进
- 任务抽屉在任务执行期间保持打开，不再很快自动收起，任务失败时也会保留在界面上。
- 官网下载页和更新日志页更新为新的 CC AI API 品牌视觉，并同步中英文页面的品牌资源。

修复
- 修复任务计划面板在任务状态变化时入口和抽屉显示不稳定的问题。
- 修复 Bark 通知请求缺少头像参数的问题。
