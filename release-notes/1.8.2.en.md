GPT Image 2.5 support

This release adds GPT Image 2.5 image generation controls and makes image models easier to use in channel accounts.

New
- GPT Image 2.5 models now use the supported landscape and portrait sizes automatically.
- Agents can request PNG, JPEG, or WebP output and set JPEG/WebP compression quality.
- Channel account settings now include an image generation model picker.

Improved
- Choosing a channel image model enables it automatically and remembers it as the default for image generation.
