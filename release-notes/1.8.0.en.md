Branding and workflow

This release brings CCCode's branding, CC API account details and task progress together in the workspace, and adds Bark notifications plus an isolated way to inspect the task drawer.

New
- The sidebar now uses the CC logo at the bottom and shows the CC API account balance when available; clicking the logo opens About.
- Structured task plans: when the agent reports tasks, an entry appears in the upper-right corner and a right-side drawer shows steps, progress, elapsed time and estimates.
- Task plans support pause, resume, retry and stop, while running and failed plans remain visible for review.
- A temporary `--task-plan-demo` launch argument demonstrates the task entry and right-side drawer with three preset tasks, isolated from real sessions.
- Bark notifications use the CC AI API logo as their default avatar, while custom and empty icon configurations remain supported.

Improved
- The task drawer stays open while a plan runs instead of disappearing shortly after it appears, and failed plans remain available in the UI.
- The download and changelog pages now use the new CC AI API brand visuals across their English and Chinese versions.

Fixed
- Task-plan entry and drawer visibility are now stable as task status changes.
- Bark notification requests now include the default icon parameter.
