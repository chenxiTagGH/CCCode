Task plan window improvements

This release makes task progress easier to follow while reducing the amount of chat content covered by the task UI.

Improved
- The task plan drawer is now a compact top-right window, up to about 360px wide and 420px tall, with rounded corners and its own scrolling list.
- The task plan no longer covers the full chat area, so the conversation remains visible while checking progress.
- The right-side tool rail now has a separate task plan entry for opening the steps and controls directly.

Fixed
- Task plans are now kept separate from the agent's plan-file page.
- The side panel safely falls back when a task plan is cleared while it is open.
